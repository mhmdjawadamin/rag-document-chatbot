# RAG Document Chatbot

A production-style Retrieval-Augmented Generation (RAG) application that allows users to upload PDF documents and chat with their contents.

## RAG Pipeline

Document Upload → Text Extraction → Chunking → Embeddings → Vector Database → Retrieval → LLM → Answer + Sources

## Planned Tech Stack

- Python
- FastAPI
- PDF Processing
- Embeddings
- Vector Database
- LLM
- Docker
